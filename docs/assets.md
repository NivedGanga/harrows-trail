# Asset provenance

The `harrows_*.png` cast textures are original pixel art generated by `tools/make-cast.py`, without input images. They use the conventional 64×32 humanoid UV layout. Project-authored assets in this document are dedicated under CC0-1.0; no attribution is required. Reproduce with `python3 tools/make-cast.py`.

The humanoid mesh is referenced from pinned Mineclonia 0.124.1 (`mcl_armor_character.b3d`, mcl_armor, based on 3D Armor by stu); it is not copied into this repository. Mineclonia's own license and media credits continue to apply when installing/distributing that game. Native horse models, item textures, armor, and sounds likewise remain supplied by the pinned game. Install the complete game, including its credits and licenses; do not extract and redistribute its media without those terms.

All cast skins are required bundled assets. The entity registration retains the native `character.png` base as a fallback before the cast layer activates; normal activation applies each original skin. Native armor/wield texture layers are preserved on Eli through `mcl_player.player_set_skin`. Removing Harrow's Trail leaves the player's native skin metadata unchanged.

No third-party character artwork, downloaded music, or unverified assets are included.
